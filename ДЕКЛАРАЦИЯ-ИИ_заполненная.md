- Запускал написанные функции на своём участке данных и проверял фактические значения `answer_1`–`answer_8`.
- Сверял тип и формат каждого ответа с требованиями задания: список / число / словарь, `float` до двух знаков, ISO-даты и т. д.
- Проверял, что суммы по `value` считаются только для строк с `ok = True`, если это требуется условием.
- Отдельно проверял работу с `Decimal`, чтобы не смешивать его с `float` до финального преобразования.
- Проверял смысл диагностических результатов на своём участке: 3 строки с `ok = False`, пересечение участников в задаче 2, лидеров в задачах 3–5, результат парсинга `RAW` и действие коэффициентов в задаче 8.
- Текстовые ответы и выводы по данным в итоговой версии писал самостоятельно.
- Перед сдачей дополнительно выполню `Kernel → Restart Kernel and Run All Cells`, чтобы убедиться, что ноутбук целиком воспроизводится с нуля.
