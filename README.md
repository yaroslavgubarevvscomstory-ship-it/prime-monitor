## Что здесь

Проект предназначен для анализа данных учебного сервиса ПРАЙМ. В рамках ДЗ-1 я работаю со своим участком таблицы `service_usage`: сегментом пользователей устройства `tablet` за заданное окно времени.

Основная работа находится в `notebooks/hw1.ipynb`. В ноутбуке выполняется загрузка данных из учебной базы, после чего на Python решаются восемь аналитических задач: анализ количества и корректности сессий, активности пользователей, распределения нагрузки по дням недели, пиковых дат и других характеристик использования сервиса.

Подключение к базе выполняется через переменную окружения `PRIME_DSN` из локального файла `.env`, поэтому логин и пароль в коде и репозитории не хранятся.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
